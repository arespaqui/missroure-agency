## 📌 Aprendizajes Clave

- **Tienda Negocio** tiene editor HTML en descripción de producto — permite fondo, tablas, badges, etc.
- **CSS global** va en Configuración → Código Externo → Head en tag `<style>`
- Los atributos `_ngcontent` de Angular son dinámicos — usar clases semánticas (.price__amount, .two-prices, etc.)
- El template de precios (labels separados) depende del plan/template de TN — contactar soporte para cambiar
- **URL del producto NO cambiar** si hay campaña activa con UTMs apuntando a esa URL
- Referencia de tienda bien optimizada en TN: perlary.tiendanegocio.com
